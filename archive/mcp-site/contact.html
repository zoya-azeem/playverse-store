Before you write

  • The FAQ covers vendor neutrality, transports, security and costs.
  • The troubleshooting table covers nearly every connection failure.

Submitting a server

To be listed in the directory, include:

  • What it connects to, in one sentence
  • Which primitives it exposes
  • Which transports it supports
  • A link to inspectable source
  • Whether it needs credentials, and which scopes

Response times

This is a volunteer-run resource, so expect days rather than hours. Corrections are handled first, then tutorial requests, then everything else.
