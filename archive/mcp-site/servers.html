No servers match that

Try a broader term, or clear the category filter.

Before you install anything. A stdio server runs as a local process with your own user's privileges. Read the source, pin an exact version, and prefer servers whose code you can inspect. Treat an MCP server the way you would treat any other dependency you are about to give filesystem access to.

Nothing here fits?

Then write your own — it is a smaller job than it looks. A useful server is often a single file: declare two or three tools, wrap the API call you already know how to make, and point your client at it.
